# Abstract 

This article addresses the challenge of data quality in anti-money laundering (AML) systems by leveraging graph-theoretic approaches to analyze sequential bank transaction data. Using two real-world anonymized datasets of suspected money laundering activity provided by law enforcement in Pernambuco, Brazil, the study models transaction sequences as multidigraphs, where nodes represent account balances and edges represent financial operations. An algorithm is proposed to identify consistent and inconsistent transaction flows by detecting closed and open Eulerian trails within these subgraphs. The methodology includes a statistical assessment of the structural properties of these graphs, employing tests such as the Kolmogorov-Smirnov test to compare transaction distributions. Results demonstrate how the proposed graph-based characterization can reveal data quality issues that may affect AML model performance. The approach, available in the open-source package mlex-lib, provides a novel tool for robust detection and analysis of illicit financial behavior in real-world AML investigations.
